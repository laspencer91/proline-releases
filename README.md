# Proline launcher releases

Public release channel for the Proline launcher. Each release carries the Windows installer
(`Proline-Setup.exe`, plus the versioned `Proline_<version>_x64-setup.exe` and its signature) and the
auto-update manifest `latest.json` that installed launchers read.

- Download the latest installer: https://github.com/laspencer91/proline-releases/releases/latest/download/Proline-Setup.exe
- Website: https://proline-game.vercel.app/download

The launcher's source code is private; this repository only holds published builds. Releases are
produced by the private repository's release workflow and signed with the project's updater key.
